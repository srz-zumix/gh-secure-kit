# GSK123 — Repository has no description

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | community |
| Fixable | No |
| ghqr equivalent | repo-meta-001 |

## Why it matters

A missing description makes it harder for contributors and security
reviewers to understand a repository's purpose at a glance, and lowers
discoverability.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK123
```

## How to fix

Add a description under **Settings → General**, or:

```sh
gh repo edit OWNER/REPO --description "..."
```
