# GSK504 — Members can create public repositories

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-sec-004 |

## Why it matters

Allowing any member to create public repositories risks accidental
disclosure of internal code, credentials, or proprietary information, and
bypasses any repository-creation review process.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK504
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK504
```
