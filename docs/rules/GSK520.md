# GSK520 — Excessive organization owners

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | access_control |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Organization owners can change every organization setting, manage billing,
and delete repositories. Each additional owner is another account whose
compromise gives an attacker full control. Following least privilege, only a
small number of trusted people should hold the owner role; gh-secure-kit
flags organizations with more than 3 owners.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK520
```

## How to fix

Review **Organization settings → People** and downgrade owners who do not
need the role to Member, granting narrower access through custom
organization roles or team repository roles instead. Not auto-fixed by
`recommended apply` since removing a role is a judgment call that should
not be automated.
