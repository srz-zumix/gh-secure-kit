# GSK126 — Issues and Discussions both disabled

| | |
|---|---|
| Severity | Low |
| Scope | Repository |
| Category | features |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | repo-feat-001 |

## Why it matters

Without Issues or Discussions enabled, there is no built-in channel for
users or researchers to report bugs or ask questions, which can push
vulnerability reports toward less appropriate public channels.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK126
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK126
```

This enables Issues. Enable Discussions instead if preferred, via
**Settings → General → Features**.
