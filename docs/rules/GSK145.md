# GSK145 - Webhook has no secret

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

A webhook secret lets the receiver authenticate event payloads. Without it,
a receiver accepting unsigned requests may act on forged events. The receiver
must verify the signature even when a secret is configured.

Only active repository webhooks are checked. GitHub returns configured secrets
masked; an empty secret is flagged, while an omitted field is indeterminate.
Unavailable metadata is skipped unless a violation is confirmed. Findings
contain hook IDs only, not secrets or endpoint URLs.

## How to check

```sh
gh secure-kit recommended check --repo my-org/my-repo --rule GSK145
```

## How to fix

Set a strong random secret in repository webhook settings and configure the
receiver to verify `X-Hub-Signature-256`. Coordinate both ends manually;
secret provisioning is not automated.
