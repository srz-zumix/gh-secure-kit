# GSK149 - AI detection of secrets not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

AI detection can identify unstructured secrets that do not match regular
patterns. It is distinct from code scanning's AI Scan.

The rule reads `secret_scanning_ai_detection`. It skips when secret scanning
is disabled or the status is unavailable.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK149
```

## How to fix

Enable scanning for AI-detected secrets in Advanced Security settings after
checking eligibility and organizational policies. This rule is read-only.
