# GSK119 — Excessive admin collaborators

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | access_control |
| Fixable | No |
| ghqr equivalent | repo-acc-001 |

## Why it matters

Every collaborator with admin access can change security settings,
manage secrets, or delete the repository. Following least privilege, only
a small number of trusted people should hold admin access; gh-secure-kit
flags repositories with more than 3 direct admin collaborators.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK119
```

## How to fix

Review **Settings → Collaborators and teams** and downgrade collaborators
who do not need admin access to Write or Maintain. Not auto-fixed by
`recommended apply` since removing access is a judgment call that should
not be automated.
