# GSK548 - Default security configurations are not enforced

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Enforcement prevents repository administrators from changing features that
the configuration explicitly enables or disables; features that are not set
are not enforced. The rule reads `enforcement` in
[default security configurations](README.md#organization-security-configuration-checks).
It accepts both `enforced` and `enterprise_enforced`.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK548
```

## How to fix

Review which features are explicitly set and the impact on repository
administrators before enforcing applicable default configurations. This rule
is read-only.
