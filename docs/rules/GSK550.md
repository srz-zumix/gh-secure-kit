# GSK550 - AI Scan for repositories not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

AI Scan can inspect repository default branches on demand. This rule reads the
organization's stored `repository_scan` setting, not a default security
configuration or each repository's effective setting. Enterprise policy can
restrict it, and repositories may opt out. Unavailable settings are skipped.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK550
```

## How to fix

Review eligibility, enterprise policy, and Code Security AI credit budgets
before enabling the organization setting. Running scans consumes credits. This
rule is read-only.
