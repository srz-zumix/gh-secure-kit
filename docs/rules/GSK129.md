# GSK129 — Conversation resolution not required before merge

| | |
|---|---|
| Severity | Low |
| Scope | Repository |
| Category | branch_protection |
| Fixable | Yes |
| ghqr equivalent | None |

## Why it matters

Without requiring open review conversations to be resolved, a pull request
can be merged while reviewer concerns (including security feedback) are
still unaddressed. The author of the pull request can still resolve a
conversation without acting on it, so this only guards against an
unresolved conversation being overlooked, not against a reviewer's concern
being deliberately ignored.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK129
```

## How to fix

Enable "Require conversation resolution before merging" under **Settings →
Branches → Branch protection rules**. `recommended apply` adds this
requirement to `gh-secure-kit/branch-protection` without modifying other
rulesets.
