# GSK122 — Unverified deploy keys

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | repo-acc-004 |

## Why it matters

An unverified deploy key has not been confirmed to work with the
repository (for example, the corresponding private key may have been
lost or never used). Stale, unverified keys increase the attack surface
without providing value.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK122
```

## How to fix

Remove unverified deploy keys under **Settings → Deploy keys**, or verify
them by using the key once. Not auto-fixed by `recommended apply`.
