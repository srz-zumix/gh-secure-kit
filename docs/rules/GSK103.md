## Why it matters

A `SECURITY.md` file tells researchers and users how to report a
vulnerability responsibly. Without it, security reports may be filed as
public issues or never reach maintainers at all.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK103
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK103
```

This creates a starter `SECURITY.md`; edit it to describe your actual
reporting process and supported versions.
