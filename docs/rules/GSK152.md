# GSK152 - GitHub Code Security not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

GitHub Code Security provides premium code and dependency security features.
The rule reads the repository's `code_security` status. It skips public
repositories, for which a product license is not required, and skips when the
status or repository visibility is unavailable.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK152
```

## How to fix

Review product eligibility, licensing, and budget before enabling Code Security
for an eligible private or internal repository. This rule is read-only.
