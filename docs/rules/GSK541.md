# GSK541 - Default configurations do not block AI-detected secrets

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Push protection for AI-detected secrets can block unstructured credentials.
This rule reads `secret_scanning_generic_secrets_push_protection` in
[default security configurations](README.md#organization-security-configuration-checks).
It skips a configuration when secret scanning, push protection, or AI
detection of secrets is disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK541
```

## How to fix

Review eligibility, credit budgets, and the prerequisite settings before
enabling this feature in applicable default configurations. Push protection for
AI-detected secrets consumes AI credits. This rule is read-only.
