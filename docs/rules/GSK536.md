# GSK536 - Default configurations do not enable secret scanning push protection

| | |
| --- | --- |
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Push protection can block supported secrets before they reach a repository.
This rule reads `secret_scanning_push_protection` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when secret scanning is disabled. It does not
evaluate pattern coverage or bypass permissions.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK536
```

## How to fix

Enable secret scanning and push protection in applicable default
configurations. This rule is read-only.
