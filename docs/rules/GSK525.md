# GSK525 - Webhook has no secret

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

A webhook without a signing secret cannot provide a shared-secret signature
for the receiver to authenticate event payloads. A receiver accepting unsigned
requests may act on forged events. Configuring a secret is insufficient unless
the receiver also verifies the signature.

Only active webhooks are checked. The per-webhook configuration is fetched
because list responses omit the secret; GitHub returns a configured secret
masked, so a missing or empty secret is flagged as unsigned. A webhook whose
configuration cannot be read is skipped unless a violation is confirmed. Findings
contain hook IDs only and never display secrets or endpoint URLs.

## How to check

```sh
gh secure-kit recommended check --owner my-org --rule GSK525
```

## How to fix

Set a strong random secret in organization webhook settings and configure the
receiver to verify `X-Hub-Signature-256`. Coordinate both ends manually;
secret provisioning is not automated.
