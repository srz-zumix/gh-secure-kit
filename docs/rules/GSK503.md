# GSK503 — Default repository permission is admin or write

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-sec-003 |

## Why it matters

The base permission level applies to every member for every repository in
the organization by default. Setting it to Admin or Write means all
members can push to (or administer) every repository unless explicitly
restricted, violating least privilege.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK503
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK503
```

This sets the base permission to Read; grant elevated access explicitly
per repository or team as needed.
