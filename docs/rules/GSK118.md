# GSK118 — Signed commits not required

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | branch_protection |
| Fixable | Yes |
| ghqr equivalent | repo-bp-012 |

## Why it matters

Requiring signed commits ensures every commit's authorship can be
cryptographically verified, making it harder to impersonate another
contributor or tamper with commit metadata.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK118
```

## How to fix

Enable "Require signed commits" under **Settings → Branches → Branch
protection rules**. `recommended apply` adds this requirement to
`gh-secure-kit/branch-protection` without modifying other rulesets.
