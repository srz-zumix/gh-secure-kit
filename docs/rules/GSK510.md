# GSK510 — Members can delete repositories

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Allowing any admin-level member to delete a repository risks irreversible
loss of code and history, whether by mistake or by a compromised account,
without requiring an organization owner to approve the action.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK510
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK510
```
