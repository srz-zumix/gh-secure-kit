# GSK529 - Default configurations do not enable Dependabot alerts

| | |
| --- | --- |
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Dependabot alerts identify vulnerable dependencies. The rule reads
`dependabot_alerts` in [default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when its dependency graph is disabled. A passing
default does not guarantee that existing repositories have alerts enabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK529
```

## How to fix

Enable Dependabot alerts and the dependency graph in each applicable default
configuration. This rule is read-only.
