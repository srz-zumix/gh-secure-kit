# GSK101 — Dependabot alerts not enabled

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | security |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | repo-sec-001 |

## Why it matters

Dependabot alerts notify you when a dependency in your repository has a
known vulnerability. Without them, vulnerable dependencies can go unnoticed
until they are exploited.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK101
gh secure-kit dependabot alerts list -R OWNER/REPO
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK101
```

Or in the GitHub UI: **Settings → Code security → Dependabot alerts → Enable**.
