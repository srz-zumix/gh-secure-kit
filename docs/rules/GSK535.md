# GSK535 - Default configurations do not enable secret scanning

| | |
| --- | --- |
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Secret scanning detects credentials exposed in repositories. This rule reads
`secret_scanning` in [default security configurations](README.md#organization-security-configuration-checks),
not the effective state of each existing repository.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK535
```

## How to fix

Review eligibility and licensing, then enable secret scanning in applicable
default configurations. This rule is read-only.
