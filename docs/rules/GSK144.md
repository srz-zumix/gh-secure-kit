# GSK144 - Webhook uses insecure transport

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

HTTP webhook endpoints expose event payloads to interception. Disabling TLS
certificate verification (`insecure_ssl=1`) permits receiver impersonation.
Signing a payload does not encrypt it.

Only active repository webhooks are checked. Unavailable or incomplete
configurations are skipped unless an unsafe hook is confirmed. Findings
contain hook IDs only. Destination trust is not checked.

## How to check

```sh
gh secure-kit recommended check --repo my-org/my-repo --rule GSK144
```

## How to fix

Use HTTPS with a valid certificate and enable SSL verification in repository
webhook settings. Endpoint changes are not automated.
