# GSK113 — Stale reviews not dismissed on new commits

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-004 |

## Why it matters

Without dismissing stale reviews, an approval given before new commits
were pushed remains valid, letting unreviewed changes merge under an
outdated approval.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK113
```

## How to fix

Enable "Dismiss stale pull request approvals when new commits are pushed"
under **Settings → Branches → Branch protection rules**. Not auto-fixed
by `recommended apply`.
