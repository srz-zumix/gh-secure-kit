# GSK527 - Default configurations do not enable dependency graph

| | |
| --- | --- |
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

The dependency graph supports visibility into a repository's dependencies and
is a prerequisite for Dependabot alerts. This rule reads `dependency_graph` in
[default security configurations](README.md#organization-security-configuration-checks)
for new repositories; it does not inspect existing repositories.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK527
```

## How to fix

Enable the dependency graph in each applicable default security configuration.
This rule is read-only.
