# GSK121 — Deploy keys with write access

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | repo-acc-003 |

## Why it matters

A deploy key with write access can push code to the repository. If that
key is leaked (for example, from a compromised server), an attacker gains
push access without needing a GitHub account. Deploy keys should be
read-only unless a specific automated write is required.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK121
gh secure-kit deps ... # see: gh secure-kit --help for deploy key commands
```

## How to fix

Remove and recreate any write-access deploy key as read-only, or replace
it with a GitHub App installation token scoped to only what is needed.
Not auto-fixed by `recommended apply` because rotating a key can break
automation that depends on it.
