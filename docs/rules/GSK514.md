# GSK514 — Fork pull request workflows run without maintainer approval

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | actions |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

The organization-wide fork pull request contributor approval policy
controls when a maintainer must approve a workflow run triggered by a pull
request from a fork. Anything looser than requiring approval for all
external contributors lets some fork-based pull requests trigger workflow
runs automatically across every repository that inherits this setting,
which is a common vector for pwn-request style attacks that exfiltrate
secrets or abuse `GITHUB_TOKEN` permissions.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK514
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK514
```
