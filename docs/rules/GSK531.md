# GSK531 - Default configurations do not enable Dependabot delegated alert dismissal

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Delegated dismissal restricts who can dismiss Dependabot alerts. This rule
reads `dependabot_delegated_alert_dismissal` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when its Dependabot alerts are disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK531
```

## How to fix

Enable prevention of direct Dependabot alert dismissals in each applicable
default configuration and establish a review process. This rule is read-only.
