# GSK546 - Default configurations do not enable GitHub Code Security

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

GitHub Code Security provides premium code and dependency security features.
This rule checks [default security configurations](README.md#organization-security-configuration-checks)
applicable to private or internal repositories. It reads `code_security` when
present, or recognizes `advanced_security` values `enabled` and `code_security`
as enabled. An absent, invalid, or ambiguous product status is skipped.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK546
```

## How to fix

Review licensing and budget before enabling Code Security in applicable
default configurations. This rule is read-only.
