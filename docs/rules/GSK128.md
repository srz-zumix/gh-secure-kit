# GSK128 — Branch deletion allowed on protected branch

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | branch_protection |
| Fixable | Yes |
| ghqr equivalent | None |

## Why it matters

If the default branch can be deleted, an attacker or a mistaken push can
remove the branch entirely, discarding its commit history and any rules
that protect it.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK128
```

## How to fix

Disable "Allow deletions" under **Settings → Branches → Branch
protection rules**. `recommended apply` adds a deletion-restriction rule to
`gh-secure-kit/branch-protection` without modifying other rulesets.
