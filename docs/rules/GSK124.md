# GSK124 — Repository has no topics

| | |
|---|---|
| Severity | Low |
| Scope | Repository |
| Category | community |
| Fixable | No |
| ghqr equivalent | repo-meta-002 |

## Why it matters

Topics improve discoverability and help classify a repository (language,
framework, purpose), which indirectly supports governance at scale (for
example, filtering repositories that should be subject to stricter
policies).

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK124
```

## How to fix

Add topics under **Settings → General**, or:

```sh
gh repo edit OWNER/REPO --add-topic TOPIC
```
