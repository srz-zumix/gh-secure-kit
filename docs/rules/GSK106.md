# GSK106 — Secret scanning not enabled

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | security |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-def-004 |

## Why it matters

Secret scanning detects credentials and tokens accidentally committed to
the repository so they can be revoked before they are abused. Note: on
private repositories this requires a GitHub Advanced Security license;
on public repositories it is available for free.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK106
gh secure-kit secret-scanning ... # see: gh secure-kit secret-scanning --help
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK106
```
