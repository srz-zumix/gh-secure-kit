# GSK136 — Environment with secrets allows self-review

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | environments |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

When an environment that holds secrets has a required reviewers rule that
allows self-review, the person who triggered the deployment workflow run
can also approve it themselves, exposing those secrets without a second
person ever looking at the deployment. Environments without any secrets
are not flagged, since self-review of a deployment with nothing sensitive
to protect is a lower-risk configuration choice.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK136
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK136
```
