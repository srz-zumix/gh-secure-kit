# GSK130 — Linear history not required

| | |
|---|---|
| Severity | Low |
| Scope | Repository |
| Category | branch_protection |
| Fixable | Yes |
| ghqr equivalent | None |

## Why it matters

Without requiring a linear history, merge commits can obscure the exact
sequence of changes landing on the default branch, making history harder
to audit.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK130
```

## How to fix

Enable "Require linear history" under **Settings → Branches → Branch
protection rules**. `recommended apply` adds this requirement to
`gh-secure-kit/branch-protection` without modifying other rulesets.
