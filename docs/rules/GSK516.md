# GSK516 — Members can create internal repositories

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Anyone who creates a repository is automatically granted admin access to
it, letting the creator configure branch protection, Actions, webhooks,
and deploy keys without going through any review process. Internal
repositories are visible to every member of the enterprise, so allowing
any member to freely create them leads to ungoverned repository sprawl
that bypasses organization defaults such as required security
configurations and base permissions.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK516
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK516
```
