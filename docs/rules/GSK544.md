# GSK544 - Default configurations do not enable private vulnerability reporting

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Private vulnerability reporting gives researchers a private way to report
vulnerabilities in public repositories. This rule reads
`private_vulnerability_reporting` in
[default security configurations](README.md#organization-security-configuration-checks)
applicable to public repositories; private/internal-only defaults are excluded.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK544
```

## How to fix

Enable private vulnerability reporting in each applicable default
configuration for public repositories. This rule is read-only.
