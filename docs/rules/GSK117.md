# GSK117 — Force pushes allowed on protected branch

| | |
|---|---|
| Severity | Critical |
| Scope | Repository |
| Category | branch_protection |
| Fixable | Yes |
| ghqr equivalent | repo-bp-010 |

## Why it matters

Force pushes can rewrite or erase commit history on the default branch,
destroying an audit trail and potentially discarding reviewed changes.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK117
```

## How to fix

Disable "Allow force pushes" under **Settings → Branches → Branch
protection rules**. `recommended apply` adds non-fast-forward protection to
`gh-secure-kit/branch-protection` without modifying other rulesets.
