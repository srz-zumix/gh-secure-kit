# GSK151 - Secret scanning delegated alert dismissal not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Delegated dismissal restricts who can dismiss secret scanning alerts. The rule
checks only the enablement status, not who can approve dismissals. It skips
when secret scanning is disabled or the status is unavailable.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK151
```

## How to fix

Enable prevention of direct alert dismissals under the repository's Advanced
Security settings and establish a review process. This rule is read-only.
