# GSK120 — Direct collaborators instead of teams

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | access_control |
| Fixable | No |
| ghqr equivalent | repo-acc-002 |

## Why it matters

Granting access to individual users directly makes it easy to lose track
of who has access and why, and complicates offboarding. Granting access
via organization teams centralizes access management and audit.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK120
```

## How to fix

Replace direct collaborators with team-based access under **Settings →
Collaborators and teams**. Not auto-fixed by `recommended apply`.
