# GSK507 — No default code security configuration for new repositories

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Without a default code security configuration, every new repository
starts with no baseline security settings (secret scanning, code
scanning, Dependabot, etc.), leaving its protection up to whoever creates
it instead of the organization's policy.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK507
```

## How to fix

Create a code security configuration and set it as the default for new
repositories under **Organization Settings → Code security → Global
settings**, or:

```sh
gh secure-kit code-security configurations set-default ID --owner ORG --default-for-new-repos all
```

Not auto-fixed by `recommended apply` since choosing which configuration
to apply is a judgment call.
