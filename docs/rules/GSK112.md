# GSK112 — Only 1 approving review required

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-003 |

## Why it matters

A single approver can be socially engineered, compromised, or simply miss
an issue. Requiring at least 2 approving reviews for sensitive
repositories provides defense in depth.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK112
```

## How to fix

Increase "Required number of approvals before merging" to 2 or more under
**Settings → Branches → Branch protection rules**. Not auto-fixed by
`recommended apply`.
