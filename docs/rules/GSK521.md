# GSK521 - Suspended users remain organization owners

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | access_control |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

A suspended owner retains an organization role that becomes effective again
if the account is unsuspended. Review obsolete privileged memberships rather
than relying on suspension as permanent access removal. Suspension itself
blocks access; this check detects retained privileges, not active access.

This rule only evaluates GitHub Enterprise Server. GitHub.com and hosted
Enterprise Cloud tenants are skipped. User profiles are fetched individually;
unreadable profiles cause a skip unless a suspended owner is already confirmed.

## How to check

```sh
gh secure-kit recommended check --owner my-org --rule GSK521
```

## How to fix

Review the suspended owners with the identity administrator and remove or
downgrade memberships that are no longer required. Removal is not automated.
