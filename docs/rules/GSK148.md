# GSK148 - Secret scanning generic patterns not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Generic patterns can detect secrets, such as private keys, that are not tied
to a particular provider. Review the additional alert volume before enabling.

The rule reads `secret_scanning_non_provider_patterns`. It skips when secret
scanning is disabled or the status is unavailable.

The setting is only available for organization-owned repositories, so the rule
skips for user-owned repositories or when the owner type is unavailable.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK148
```

## How to fix

Enable generic patterns under the repository's Advanced Security settings.
This rule is read-only.
