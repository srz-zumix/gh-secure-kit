# GSK150 - Secret scanning delegated bypass not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Delegated bypass adds review of push protection bypass requests. The rule
checks the enablement status only; it does not inspect reviewers, exemptions,
or the effectiveness of the review process. It skips when secret scanning or
push protection is disabled or the status is unavailable.

The setting is only available for organization-owned repositories, so the rule
skips for user-owned repositories or when the owner type is unavailable.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK150
```

## How to fix

Enable delegated bypass and configure appropriate reviewers under Advanced
Security settings. This rule does not change settings or reviewer lists.
