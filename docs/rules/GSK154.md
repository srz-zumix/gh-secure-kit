# GSK154 - AI Scan for pull requests not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

AI Scan can identify vulnerabilities in eligible pull requests. The rule
reads the repository's `pr_scan` setting, not scan results, language coverage,
or remaining budget. An unavailable or unsupported setting is skipped.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK154
```

## How to fix

Review eligibility, organization policy, and Code Security AI credit budgets
before enabling AI Scan for pull requests. Qualifying scans can consume credits.
This rule is read-only.
