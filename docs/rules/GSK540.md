# GSK540 - Default configurations do not enable AI detection of secrets

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

AI detection can identify unstructured secrets that do not match regular
patterns. This rule reads `secret_scanning_generic_secrets` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when secret scanning is disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK540
```

## How to fix

Review eligibility and organizational policies, then enable scanning for
AI-detected secrets in applicable default configurations. This rule is read-only.
