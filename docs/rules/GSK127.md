# GSK127 — Repository appears dormant but is not archived

| | |
|---|---|
| Severity | Low |
| Scope | Repository |
| Category | maintenance |
| Fixable | No |
| ghqr equivalent | repo-meta-003 |

## Why it matters

Repositories with no activity in over two years are unlikely to receive
security patches. Leaving them unarchived may mislead users into treating
them as maintained, and unpatched code remains a soft target.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK127
```

## How to fix

If the repository is genuinely inactive, archive it under **Settings →
General → Danger Zone → Archive this repository**. If it is still
maintained through infrequent pushes, no action is required. Not
auto-fixed by `recommended apply` since archiving is a judgment call.
