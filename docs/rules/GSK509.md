# GSK509 — Members can fork private repositories

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Forking a private repository copies its full history and contents into a
member's personal fork, which can leak proprietary code or secrets outside
the organization's access controls and audit log.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK509
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK509
```
