# GSK513 — Actions can approve pull requests

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | actions |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Allowing GitHub Actions to submit approving pull request reviews
organization-wide lets a workflow satisfy a required-reviewers branch
protection rule on its own, defeating the purpose of mandatory human
review across every repository that inherits this setting. A workflow
triggered by an attacker-controlled input could self-approve a malicious
pull request.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK513
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK513
```
