# GSK104 — No CODEOWNERS file found

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | repo-sec-005 |

## Why it matters

A `CODEOWNERS` file lets you require review from the right people or teams
before changes are merged. Without it, any collaborator with write access
can approve pull requests, including for sensitive paths.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK104
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK104
```

This creates a starter `.github/CODEOWNERS`; edit it to list the correct
owners for each path. Combine with branch protection's "Require review
from Code Owners" (see [GSK114](GSK114.md)) to enforce it.
