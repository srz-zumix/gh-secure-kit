# GSK102 — Dependabot enabled but no dependabot.yml found

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | repo-sec-006 |

## Why it matters

Dependabot alerts tell you about vulnerable dependencies, but without a
`.github/dependabot.yml` configuration file, Dependabot will not open
automated pull requests to keep dependencies up to date, so known issues
can persist longer than necessary.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK102
```

## How to fix

Add a `.github/dependabot.yml` file to the repository, for example:

```yaml
version: 2
updates:
  - package-ecosystem: "github-actions"
    directory: "/"
    schedule:
      interval: "weekly"
```
