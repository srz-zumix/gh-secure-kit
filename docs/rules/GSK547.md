# GSK547 - Default configurations do not enable GitHub Secret Protection

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

GitHub Secret Protection provides premium secret scanning and prevention
features. This rule checks [default security configurations](README.md#organization-security-configuration-checks)
applicable to private or internal repositories. It reads `secret_protection`
when present, or recognizes `advanced_security` values `enabled` and
`secret_protection` as enabled. An absent, invalid, or ambiguous product
status is skipped.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK547
```

## How to fix

Review licensing and budget before enabling Secret Protection in applicable
default configurations. This rule is read-only.
