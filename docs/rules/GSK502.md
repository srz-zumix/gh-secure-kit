# GSK502 — Web commit signoff not required

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-sec-002 |

## Why it matters

Commits made through the GitHub web UI are not signed by default.
Requiring signoff on web-based commits keeps commit provenance consistent
with signed-commit policies (see [GSK118](GSK118.md)) for changes made
outside a local, signing-enabled Git client.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK502
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK502
```
