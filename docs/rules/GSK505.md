# GSK505 — No security manager team assigned

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | org-sec-005 |

## Why it matters

The security manager role lets a team view and manage security alerts
across every repository they are granted access to, without needing full
admin rights. Without one assigned, security work is either concentrated
in organization owners or lacks org-wide visibility.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK505
```

## How to fix

Assign a team the security manager role under **Organization Settings →
Repository → Security managers**. Not auto-fixed by `recommended apply`
since choosing the right team is a judgment call.
