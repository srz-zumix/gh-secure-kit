# GSK111 — No approving reviews required before merge

| | |
|---|---|
| Severity | Critical |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-002 |

## Why it matters

If zero approving reviews are required, a single author can merge
unreviewed code directly to the default branch, removing the primary
control against unintentional or malicious changes.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK111
```

## How to fix

Set "Require a pull request before merging" with at least 1 required
approving review under **Settings → Branches → Branch protection rules**
(or the equivalent ruleset). Not auto-fixed by `recommended apply` to
avoid overwriting unrelated protection settings.
