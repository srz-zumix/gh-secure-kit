# GSK508 — Actions enabled for all repositories

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | actions |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Enabling GitHub Actions for every repository, including ones that never
need it, widens the attack surface for supply-chain risks such as
compromised third-party actions and malicious workflow changes.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK508
```

## How to fix

Restrict Actions to selected repositories under **Organization Settings →
Actions → General → Policies**. Not auto-fixed by `recommended apply`
since selecting which repositories need Actions is a judgment call.
