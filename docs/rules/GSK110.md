# GSK110 — No branch protection configured on default branch

| | |
|---|---|
| Severity | Critical |
| Scope | Repository |
| Category | branch_protection |
| Fixable | Yes |
| ghqr equivalent | repo-bp-001 |

## Why it matters

Without a branch protection rule or ruleset on the default branch, anyone
with write access can push directly to it, force-push over history, or
merge without review — bypassing CI and code review entirely.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK110
```

## How to fix

`recommended apply` creates the repository-owned
`gh-secure-kit/branch-protection` ruleset when no protection exists. It targets
the default branch with active enforcement and adds only non-fast-forward
protection. Configure review requirements and required status checks separately.

This repository's rulesets can be inspected with:

```sh
gh api repos/OWNER/REPO/rulesets
```

For manual configuration, use **Settings → Branches** or
**Settings → Rules → Rulesets**.
