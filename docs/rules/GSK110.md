# GSK110 — No branch protection configured on default branch

| | |
|---|---|
| Severity | Critical |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-001 |

## Why it matters

Without a branch protection rule or ruleset on the default branch, anyone
with write access can push directly to it, force-push over history, or
merge without review — bypassing CI and code review entirely.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK110
```

## How to fix

Configure either a classic branch protection rule or a repository ruleset
targeting the default branch, requiring at minimum pull request reviews
and passing status checks. This repository's rulesets can be inspected
with:

```sh
gh api repos/OWNER/REPO/rulesets
```

Because reconstructing a safe protection configuration automatically risks
weakening existing rules, this check is not auto-fixed by
`recommended apply`; configure it via **Settings → Branches** or
**Settings → Rules → Rulesets**.
