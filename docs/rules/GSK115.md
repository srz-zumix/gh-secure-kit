# GSK115 — Strict status checks not enabled

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-007 |

## Why it matters

Without requiring branches to be up to date before merging, a pull request
can merge with status checks that passed against an older version of the
base branch, potentially merging code that would fail CI against current
`main`.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK115
```

## How to fix

Enable "Require branches to be up to date before merging" under
**Settings → Branches → Branch protection rules**. Not auto-fixed by
`recommended apply`.
