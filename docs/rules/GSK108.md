# GSK108 — Private vulnerability reporting not enabled

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-def-007 |

## Why it matters

Private vulnerability reporting gives external researchers a built-in,
private channel to report vulnerabilities directly through GitHub, instead
of filing a public issue or having no clear channel at all.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK108
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK108
```
