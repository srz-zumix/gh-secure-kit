# GSK545 - Default configurations do not enable the GitHub Advanced Security bundle

| | |
| --- | --- |
| Severity | Info |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

The GitHub Advanced Security bundle includes Code Security and Secret
Protection. This rule reads `advanced_security` in
[default security configurations](README.md#organization-security-configuration-checks)
applicable to private or internal repositories. A standalone product value is
skipped rather than interpreted as bundle status.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK545
```

## How to fix

Review licensing, standalone product choices, and budget before enabling the
bundle in applicable default configurations. This rule is read-only.
