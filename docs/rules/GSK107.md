# GSK107 — Secret scanning push protection not enabled

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | security |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-def-005 |

## Why it matters

Push protection blocks commits that contain a detectable secret *before*
they reach GitHub, instead of only alerting after the fact. This is
strictly stronger than secret scanning alone.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK107
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK107
```

Requires secret scanning ([GSK106](GSK106.md)) to be enabled first.
