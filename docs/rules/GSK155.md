# GSK155 - AI Scan for repositories not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

AI Scan can inspect the repository's default branch on demand. The rule reads
the `repository_scan` enablement setting; it does not run a scan or verify its
results. An unavailable or unsupported setting is skipped.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK155
```

## How to fix

Review eligibility, organization policy, and Code Security AI credit budgets
before enabling AI Scan for repositories. Running scans consumes credits. This
rule is read-only.
