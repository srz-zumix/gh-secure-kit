# GSK534 - Default configurations do not enable code scanning delegated alert dismissal

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Delegated dismissal restricts who can dismiss code scanning alerts. This rule
reads `code_scanning_delegated_alert_dismissal` in
[default security configurations](README.md#organization-security-configuration-checks);
it does not inspect existing repository settings or reviewer permissions.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK534
```

## How to fix

Enable prevention of direct code scanning alert dismissals in applicable default
configurations and establish a review process. This rule is read-only.
