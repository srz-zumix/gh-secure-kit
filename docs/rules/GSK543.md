# GSK543 - Default configurations do not enable secret scanning extended metadata

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Extended metadata checks can provide additional context for exposed
credentials. This rule reads `secret_scanning_extended_metadata` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when secret scanning or validity checks are disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK543
```

## How to fix

Review the information collected and the privacy implications of validity
checks before enabling extended metadata in applicable default configurations.
Validity checks send supported detected credentials to their issuers.
This rule is read-only.
