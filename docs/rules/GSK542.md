GSK542 - Default configurations do not enable secret scanning
delegated alert dismissal
================================================================

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

Why it matters
--------------

Delegated dismissal restricts who can dismiss secret scanning alerts. This rule
reads `secret_scanning_delegated_alert_dismissal` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when secret scanning is disabled.

How to check
------------

```sh
gh secure-kit recommended check --owner ORG --rule GSK542
```

How to fix
----------

Enable prevention of direct secret scanning alert dismissals in applicable
default configurations and establish a review process. This rule is read-only.
