# GSK532 - Default configurations do not enable Dependabot reachability analysis

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Reachability analysis helps prioritize Dependabot alerts by examining whether
vulnerable dependency code can be called. The rule reads
`dependabot_reachability` in [default security configurations](README.md#organization-security-configuration-checks).
The API may omit this setting when the feature is unavailable; that is skipped.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK532
```

## How to fix

Check feature availability, supported ecosystems, and Dependabot alert
prerequisites, then enable reachability analysis in applicable default
configurations. This rule is read-only.
