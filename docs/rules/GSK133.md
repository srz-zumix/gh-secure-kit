# GSK133 — Actions can approve pull requests

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | actions |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Allowing GitHub Actions to submit approving pull request reviews lets a
workflow satisfy a required-reviewers branch protection rule on its own,
defeating the purpose of mandatory human review. A workflow triggered by an
attacker-controlled input could self-approve a malicious pull request.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK133
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK133
```
