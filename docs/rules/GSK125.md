# GSK125 — Auto-delete branches on merge not enabled

| | |
|---|---|
| Severity | Low |
| Scope | Repository |
| Category | maintenance |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | repo-feat-002 |

## Why it matters

Leaving merged branches around clutters the repository and can lead to
confusion about which branches are still active, occasionally resulting
in accidental reuse of stale branches.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK125
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK125
```
