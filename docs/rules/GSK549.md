# GSK549 - AI Scan for pull requests not enabled

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

AI Scan can identify vulnerabilities in eligible pull requests. This rule reads
the organization's stored `pr_scan` setting, not a default security
configuration or the effective setting of each repository. Enterprise policy
can restrict it, and repositories may opt out. Unavailable settings are skipped.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK549
```

## How to fix

Review eligibility, enterprise policy, and Code Security AI credit budgets
before enabling the organization setting. Enabling it can start scanning eligible
repositories immediately and consume credits. This rule is read-only.
