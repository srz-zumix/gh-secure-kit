# GSK116 — No required status checks configured

| | |
|---|---|
| Severity | High |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-009 |

## Why it matters

Without any required status checks, CI failures (failing tests, lint
errors, security scans) do not block merges, so broken or insecure code
can reach the default branch.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK116
```

## How to fix

Add required status checks (e.g. your CI workflow's job names) under
**Settings → Branches → Branch protection rules → Require status checks
to pass before merging**. Not auto-fixed by `recommended apply`.
