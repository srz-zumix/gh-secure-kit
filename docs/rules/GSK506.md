# GSK506 — Actions allows all third-party actions and reusable workflows

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | actions |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-act-002 |

## Why it matters

Allowing any GitHub Action (including unverified third-party actions) to
run means a compromised or malicious action anywhere in the marketplace
can execute arbitrary code in your CI/CD pipelines, potentially exposing
secrets or supply-chain access.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK506
gh secure-kit actions ... # see: gh secure-kit actions --help
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK506
```

This restricts allowed actions to "selected"; you must then explicitly
allow the specific actions and reusable workflows your organization uses
under **Organization Settings → Actions → General**.
