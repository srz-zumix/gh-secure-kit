# GSK153 - GitHub Advanced Security bundle not enabled

| | |
| --- | --- |
| Severity | Info |
| Scope | Repository |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

The GitHub Advanced Security bundle includes Code Security and Secret
Protection. This rule checks the repository's `advanced_security` status,
not whether individual standalone products are enabled. Choosing standalone
products instead of the bundle can be intentional.

Public repositories and repositories with unknown visibility or unavailable
bundle status are skipped.

## How to check

```sh
gh secure-kit recommended check --repo OWNER/REPO --rule GSK153
```

## How to fix

Review licensing, existing standalone products, and budget before enabling
the bundle for an eligible private or internal repository. This rule is
read-only.
