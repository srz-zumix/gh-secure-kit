# GSK515 — Members can create private repositories

| | |
|---|---|
| Severity | Medium |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Anyone who creates a repository is automatically granted admin access to
it, letting the creator configure branch protection, Actions, webhooks,
and deploy keys without going through any review process. Allowing any
member to freely create private repositories leads to ungoverned
repository sprawl without centralized review or inventory.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK515
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK515
```
