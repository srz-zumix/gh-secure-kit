# GSK114 — Code owner review not required

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | branch_protection |
| Fixable | No |
| ghqr equivalent | repo-bp-005 |

## Why it matters

Even with a [CODEOWNERS](GSK104.md) file in place, its assignments are
only enforced when "Require review from Code Owners" is also enabled;
otherwise anyone can approve changes to code owned by someone else.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK114
```

## How to fix

Enable "Require review from Code Owners" under **Settings → Branches →
Branch protection rules**. Not auto-fixed by `recommended apply`.
