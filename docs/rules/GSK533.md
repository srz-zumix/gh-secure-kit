# GSK533 - Default configurations do not enable code scanning default setup

| | |
| --- | --- |
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Code scanning default setup helps detect vulnerabilities automatically. This
rule reads `code_scanning_default_setup` in
[default security configurations](README.md#organization-security-configuration-checks).
It does not determine whether individual repositories use advanced setup or
successfully produce scan results.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK533
```

## How to fix

Review language support and runner requirements, then enable default setup in
applicable default configurations. This rule is read-only.
