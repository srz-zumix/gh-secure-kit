# GSK537 - Default configurations do not enable secret scanning delegated bypass

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Delegated bypass adds review of push protection bypass requests. This rule
reads `secret_scanning_delegated_bypass` in
[default security configurations](README.md#organization-security-configuration-checks).
It skips a configuration when secret scanning or push protection is disabled,
and does not inspect the reviewer or exemption lists.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK537
```

## How to fix

Enable delegated bypass and configure appropriate reviewers in applicable
default configurations. This rule is read-only.
