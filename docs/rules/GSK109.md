# GSK109 — Dependabot security updates not enabled

| | |
|---|---|
| Severity | Medium |
| Scope | Repository |
| Category | security |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | org-def-002 |

## Why it matters

Dependabot security updates (also called automated security fixes)
automatically open pull requests to upgrade vulnerable dependencies once a
Dependabot alert is raised, reducing the time-to-patch.

## How to check

```sh
gh secure-kit recommended check -R OWNER/REPO --rule GSK109
```

## How to fix

```sh
gh secure-kit recommended apply -R OWNER/REPO --rule GSK109
```

Requires Dependabot alerts ([GSK101](GSK101.md)) to be enabled first.
