# GSK528 - Default configurations do not enable automatic dependency submission

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Automatic dependency submission can add transitive dependencies to the graph.
The rule reads `dependency_graph_autosubmit_action` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when its dependency graph is disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK528
```

## How to fix

Review workflow usage and runner requirements, then enable automatic dependency
submission in each applicable default configuration. It runs GitHub-managed
workflows and may affect runner usage. This rule is read-only.
