# GSK511 — Members can change repository visibility

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | access_control |
| Fixable | Yes (`recommended apply`) |
| ghqr equivalent | None |

## Why it matters

Allowing any admin-level member to change a repository's visibility risks
an accidental or malicious switch from private to public, exposing
proprietary code or secrets, without requiring an organization owner to
approve the change.

## How to check

```sh
gh secure-kit recommended check -o ORG --rule GSK511
```

## How to fix

```sh
gh secure-kit recommended apply -o ORG --rule GSK511
```
