# GSK524 - Webhook uses insecure transport

| | |
|---|---|
| Severity | High |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

An active webhook using HTTP exposes event payloads to interception. Disabling
TLS certificate verification (`insecure_ssl=1`) permits impersonation of the
receiver. Webhook signatures authenticate payloads but do not encrypt them.

Only active webhooks are checked. Unreadable or incomplete configurations are
skipped unless an unsafe hook is confirmed. Findings contain hook IDs, not
endpoint URLs or secrets. This rule does not validate destination trust.

## How to check

```sh
gh secure-kit recommended check --owner my-org --rule GSK524
```

## How to fix

Configure an HTTPS endpoint with a valid certificate and enable SSL verification
in organization webhook settings. Endpoint changes are not automated.
