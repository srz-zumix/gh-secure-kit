# GSK539 - Default configurations do not enable secret scanning generic patterns

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Generic patterns can detect secrets, such as private keys, that are not tied
to a particular provider. This rule reads `secret_scanning_non_provider_patterns`
in [default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when secret scanning is disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK539
```

## How to fix

Review the potential alert volume, then enable generic patterns in applicable
default configurations. This rule is read-only.
