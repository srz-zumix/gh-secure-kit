# GSK522 - Suspended users remain organization members

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | access_control |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

A suspended member can regain organization access after unsuspension. Review
retained memberships as part of account offboarding. Suspension blocks current
access, so a finding does not mean the suspended account can currently sign in.
Owners are checked separately by GSK521.

The shared user classifier detects a non-null `suspended_at` on GitHub
Enterprise Server or an obfuscated Enterprise Managed User (EMU) login matching
`<hexadecimal hash>_<shortcode>` (at least 30 hash characters) on Enterprise
Cloud, including GitHub.com and hosted tenants. EMU detection is a naming-pattern
heuristic, not an authoritative suspension API. Ordinary cloud accounts do not
expose their suspension status; a pass means no matching suspension indicators.

Only Enterprise Server requires individual profile lookups for members without
existing suspension indicators. Unreadable profiles or member lists cause a
skip unless a suspended member is already confirmed.

## How to check

```sh
gh secure-kit recommended check --owner my-org --rule GSK522
```

## How to fix

Review retained memberships and remove accounts that no longer need access.
Temporary suspensions may be intentional; removal is not automated.
