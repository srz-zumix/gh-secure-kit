# GSK530 - Default configurations do not enable Dependabot security updates

| | |
| --- | --- |
| Severity | Medium |
| Scope | Organization |
| Category | security |
| Fixable | No |
| ghqr equivalent | None |

## Why it matters

Dependabot security updates can open pull requests to fix vulnerable
dependencies. The rule reads `dependabot_security_updates` in
[default security configurations](README.md#organization-security-configuration-checks)
and skips a configuration when its Dependabot alerts are disabled.

## How to check

```sh
gh secure-kit recommended check --owner ORG --rule GSK530
```

## How to fix

Enable Dependabot security updates in each applicable default configuration
after considering the automated pull request workflow. This rule is read-only.
